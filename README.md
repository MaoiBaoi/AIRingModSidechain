# RingModSidechain (VST3)

Ringmodulator mit Sidechain-Eingang.
Haupteingang x Sidechain-Eingang = Ausgang.

Regler: Wet/Dry (0-100 %), Volume (-24 bis +24 dB).
Doppelklick auf einen Regler setzt ihn auf den Standardwert zurueck.

## Die .vst3 bauen lassen
1. Alle Dateien (inkl. Ordner .github) in ein neues GitHub-Repository hochladen.
2. Im Tab "Actions" den Lauf "Build VST3" abwarten (ca. 10 Minuten).
3. Im fertigen Lauf unten unter "Artifacts" den Download "RingModSidechain-VST3-Windows" holen.
4. Entpacken und den Ordner "RingModSidechain.vst3" nach
   C:\Program Files\Common Files\VST3\   kopieren.
5. In der DAW die Plugins neu scannen.
